### Concurrency


Goroutine : OS thread위에 multiplex 되는 실행단위

---

**_Concept_**

- **Concurrency** :  여러 작업을 논리적으로 동시에 다루는 구조
- **Parallelism** :  여러 작업을 물리적으로 동시에 실행.  멀티코어 필요
- **Green Tread** : OS가 아닌 런타임이 관리하는 경량 스레드 개념
